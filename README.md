# 🏆 FIFA World Cup Explorer

An interactive Streamlit web app that lets football fans explore World Cup history, stats, and stories — all in one place, with a bracket predictor for 2026.

## ✨ Features

- 🏟️ **Venues** — Browse 50+ stadiums across five World Cup editions with fun facts and city info
- 📖 **World Cup Stories** — Key historical moments and narratives from past tournaments
- 📊 **Analytics** — Golden Boot, Golden Ball, assists, and card totals broken down by year
- 🧠 **Quiz** — Scored trivia mode to test your World Cup knowledge
- 🔮 **2026 Bracket** — Predict outcomes across 12 national teams using live tournament data
- 🎨 **Custom UI** — Dark-themed design with glowing tab borders and a stadium-tunnel login experience

## 🛠️ Tech Stack

- **Python**
- **Streamlit** — app framework and UI
- **Pandas** — data handling and analytics
- **Custom CSS** — styling and animations

## 🚀 Getting Started

### Prerequisites
- Python 3.9+
- pip

### Installation

```bash
git clone https://github.com/yourusername/worldcup-explorer.git
cd worldcup-explorer
pip install -r requirements.txt
streamlit run worldcup.py
```
